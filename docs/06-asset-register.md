# فهرست منابع تصویری و فونت

تمام عکس‌های این نسخه به‌طور اختصاصی با مدل تولید تصویر برای **نمونه‌سازی کانوکس** ساخته شده‌اند. هیچ‌یک عکس مستند محصول کارخانه، اثبات مشخصات یا تصویر دارای تأیید رسمی سازنده نیست. از تصاویر رقبای مرجع در سایت استفاده نشده است.

| منبع در `assets-source/` | کاربرد                                                |
| ------------------------ | ----------------------------------------------------- |
| `hero.png`               | ترکیب خانواده ابزار روی سطوح بتنی؛ hero و جلد کاتالوگ |
| `chisels.png`            | تصویر خانواده قلم بتن‌کن                              |
| `caster.png`             | تصویر خانواده چرخ صنعتی                               |
| `level.png`              | تصویر خانواده تراز                                    |
| `laser.png`              | تصویر خانواده متر لیزری                               |
| `abrasives.png`          | تصویر خانواده برش/ساب                                 |
| `workshop.png`           | صحنه مفهومی کارگاه و کاربرد ابزار                     |
| `measurement.png`        | صحنه مفهومی اندازه‌گیری در پروژه                      |
| `accessories.png`        | کیف و بند دستگاه؛ متعلقات نمونه                       |

چند مدل یک خانواده عمداً از یک تصویر نمونه مشترک استفاده می‌کنند؛ تنوع مشخصات به معنی وجود عکس واقعی تک‌تک SKUها نیست. نوشته یا جزئیات ریز تولیدشده روی ابزار ممکن است دقیق نباشد. برای انتشار عمومی، عکس تأییدشده همان مدل جایگزین شود.

نسخه‌های WebP در `public/images/`، اندازه‌های responsive در `data/image-manifest.json` و اسکریپت بازتولید در `scripts/optimize-images.mjs` هستند. مسیر `data/uploads/` برای تصاویر واقعی بارگذاری‌شده از پنل است.

فونت: Vazirmatn Variable، پروژه Rastikerdar، با مجوز SIL Open Font License. فایل محلی و متن مجوز در `public/fonts/` قرار دارند. نشانه‌نوشتاری KONVEX پیاده‌سازی تایپوگرافیک اولیه است و باید با هویت رسمی صاحب برند تطبیق داده شود.

## تغییرات نسخه ۲

نسخه‌های رنگی جدا برای hero، laser، caster، level، abrasives و measurement در `public/images/green/` ساخته شده‌اند. منبع قبلی و مسیر ذخیره‌شده در دیتابیس حفظ شده است؛ این تغییر نمایشی روی تصاویر نمونه انجام شده، نه عکس‌های بارگذاری‌شده کاربر. Hero نسخه AVIF با fallback WebP دارد. Inter محلی و subset رابط از Vazirmatn به همراه فونت‌ها و مجوزهای اصلی نگهداری می‌شوند.
