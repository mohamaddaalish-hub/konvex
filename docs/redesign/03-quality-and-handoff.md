# Konvex — تحویل Redesign سبز و دو زبانه

۷ سپتامبر ۲۰۲۶ — نسخه ۲ روی پروژه موجود. **داده‌های اصلی و عملکرد قبلی حفظ شده‌اند؛ این پروژه از صفر بازنویسی نشده است.**

## آنچه تحویل شد

- هویت سبز، سطوح نیمه‌شفاف، header شناور/چسبان و footer شیشه‌ای؛ سیستم یکپارچه رنگ، radius، border، سایه، فونت و فاصله.
- Light و Dark مستقل از زبان، با ذخیره ترجیح، bootstrap پیش از paint و fallback خوانا.
- نسخه فارسی با مسیرهای اصلی و نسخه کامل انگلیسی با `/en`؛ layout و فلش‌های وابسته به جهت، RTL/LTR هستند.
- ترجمه UI، پیام‌ها، فرم‌ها، مشخصات و توضیحات ۳۲ محصول، شش دسته، شش کاربرد، برند و پنج مقاله؛ پنل مدیریت و پنل مستقل ویرایش ترجمه.
- حفظ search/filter/pagination/compare/wishlist/quote/API؛ حفظ مقادیر فرم و کد پیگیری هنگام تغییر زبان.
- پس‌زمینه canvas آرام، scroll boost محدود، کاهش تعداد/نرخ رندر در موبایل، pause کاربر، توقف در تب پنهان و reduced-motion.
- PDF فارسی و انگلیسی و برگه HTML دو زبانه، با هویت سبز و جهت درست.

| نوع بررسی                                   | نتیجه                                       |

سناریوها شامل جستجوی فارسی/انگلیسی و ارقام/واحدها، انتخاب با keyboard، فیلتر ترکیبی، مقایسه سه‌تایی و رد دسته متفاوت، فقط تفاوت‌ها، استعلام گروهی، خطا و retry فرم، idempotency، ورود/خروج و CRUD، upload، metadata و 404 واقعی هستند.

سناریوهای جدید، عدم reload کامل هنگام تغییر زبان، حفظ query/hash، پایداری تم، حفظ draft و رسید استعلام، عدم ذخیره PII فرم در localStorage، جهت keyboard، pause/reduced-motion ذرات و عدم تغییر متن فارسی هنگام ویرایش انگلیسی را هم بررسی می‌کنند. یک محصول موقت با ترجمه جدید برای آزمون dictionary پویا ساخته و حذف شد.

WebKit/Chromium با viewport و touch موبایل شبیه‌سازی شده‌اند؛ **این نتیجه معادل آزمایش سخت‌افزار واقعی iPhone/Android یا تمام نسخه‌های Safari نیست.** تست صفحه‌خوان واقعی و مصرف باتری میدانی نیز ادعا نمی‌شود.

## Lighthouse — آخرین سنجش ثبت‌شده

Production build، Chromium، موبایل throttled پیش‌فرض Lighthouse و دسکتاپ 1440×1000. تصاویر و داده نمونه، سرویس محلی sandbox. جدول بهترین نتیجه منتخب نیست؛ آخرین فایل‌های ثبت‌شده را نشان می‌دهد.

| صفحه                   | Performance | Accessibility | Best practices |    LCP |   CLS |    TBT |
| ---------------------- | ----------: | ------------: | -------------: | -----: | ----: | -----: |
| خانه فارسی / موبایل    |          95 |           100 |            100 | 2.79 s | 0.000 | 106 ms |
| خانه انگلیسی / موبایل  |          97 |           100 |            100 | 2.62 s | 0.000 |  62 ms |
| دسته انگلیسی / موبایل  |          95 |           100 |            100 | 2.83 s | 0.000 |  96 ms |
| محصول انگلیسی / موبایل |          94 |           100 |            100 | 3.03 s | 0.000 | 101 ms |
| خانه انگلیسی / دسکتاپ  |         100 |           100 |            100 | 0.75 s | 0.000 |  14 ms |

امتیاز عملکرد این نمونه‌ها در محدوده ۹۴ تا ۱۰۰ قرار دارد، اما شبکه و دستگاه واقعی نتیجه را تغییر می‌دهند. برخی LCPهای موبایل هنوز بالاتر از ۲٫۵ ثانیه‌اند؛ قبولی قطعی Core Web Vitals میدانی ادعا نمی‌شود. INP واقعی پس از ترافیک عملیاتی باید اندازه‌گیری شود.

SEO امتیاز ۶۹ دارد؛ محافظ noindex نمونه و robots مسدودکننده عمداً حفظ شده‌اند. canonical/hreflang متعارض اصلاح شده و فقط metadata پیکربندی‌شده مرجع است. برای افزایش نمره، سایت نمونه ایندکس‌پذیر نشده است.

کاهش هزینه اجرا: فونت‌های subset محلی، AVIF hero با fallback، یک CSS تولیدی به‌جای importهای مسدودکننده متعدد، memo دیکشنری/تنظیمات و عدم رندر React برای هر فریم ذرات.

## بررسی مقیاس

روی یک دیتابیس آزمایشی جدا با ۵۰۰۰ محصول و ترجمه، payload دیکشنری مسیرهای آزمایش‌شده تقریباً 43.6 تا 44.4 KiB بود؛ تمام ترجمه‌ها به هر صفحه ارسال نمی‌شوند. میانگین ساخت scope/query/dictionary حدود 9.8 تا 47.2 ms ثبت شد.

این اعداد آزمون repository محلی‌اند، نه تضمین ظرفیت بار هم‌زمان، serverless یا چند replica. معماری دیسک پایدار SQLite نسخه قبلی همچنان پابرجاست.

## اسناد و بازبینی بصری

دو PDF هفت‌صفحه‌ای، هر یک با ۳۲ SKU یکتا، تولید و بازبینی شدند. جهت نسخه فارسی RTL و انگلیسی LTR است. کنترل سرریز، نمونه بودن داده و نبود متن موقت آزمون انجام شد. برگه HTML محصول نیز زبان و جهت را از درخواست می‌گیرد.

خانه، دسته، محصول، استعلام، پنل مدیریت و PDF بازبینی تصویری شدند. تصاویر نهایی در `qa/final-*.webp` هستند. تصاویر lazy برای بررسی نهایی decode شدند؛ هیچ تصویر خراب در این بررسی گزارش نشد. منابع و فایل‌های تصویر قبلی محفوظ‌اند و نسخه‌های سبز جداگانه‌اند.

## امنیت و موارد انتشار

اعتبارسنجی، CSRF، Origin، نشست امضاشده، rate limit و حفاظت رسانه قبلی حفظ شده‌اند؛ API ویرایش ترجمه هم احراز هویت، CSRF و محدودیت payload دارد. audit runtime صفر مورد گزارش‌شده و audit ابزارهای توسعه ۲۰ مورد (۱۶ متوسط و ۴ بالا) دارد؛ جزئیات خام در `qa/audit-*.json` است. این نتیجه تضمین نبود آسیب‌پذیری یا ممیزی امنیتی مستقل نیست.

پیش از انتشار واقعی: اطلاعات/عکس/اسناد رسمی، نشانی و تماس، سیاست حقوقی و نگهداری داده، دامنه واقعی، TLS/proxy و سرویس پاسخ‌گویی باید نهایی شوند. پرداخت، پیامک، ایمیل خودکار و CRM اضافه نشده‌اند. قابلیت‌های قبلی به‌خاطر Redesign حذف نشده‌اند.

## استفاده و فایل‌های تحویل

- فارسی: `/`؛ انگلیسی: `/en`.
- پنل: `/admin` یا `/en/admin`؛ ترجمه: `?tab=translations`.
- کنترل نور و زبان در header؛ کنترل توقف حرکت در footer.
- برای فرم‌ها/مدیریت در پیش‌نمایش iframe، اگر مرورگر کوکی ثالث را محدود می‌کند، سایت را در تب مستقل باز کنید.
- راهنمای فنی و نگهداری: `02-implementation.md`.
- فایل‌ها: `konvex-redesign-source.zip` و دو PDF در `public/downloads/`.

آرشیو سورس فاقد رمز، env واقعی، دیتابیس‌های اصلی/آزمون، بکاپ و traceهای حساس است. دستورهای نصب و ایجاد env تازه در README هستند؛ در محیط فعلی رمز همان رمز قبلی است.
