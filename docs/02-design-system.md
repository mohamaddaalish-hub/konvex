# سیستم طراحی جاری Konvex — Green / Glass

نسخه ۲، سپتامبر ۲۰۲۶. این سند جایگزین پالت نارنجی نسخه اولیه است.

مرجع کامل پیاده‌سازی: [راهنمای Redesign](redesign/02-implementation.md).

## توکن‌های اصلی

| نقش        | Light     | Dark      |
| ---------- | --------- | --------- |
| سبز برند   | `#167451` | `#4CD49A` |
| hover      | `#105D40` | `#6FE1B2` |
| متن اصلی   | `#14241C` | `#EDF4EF` |
| متن ثانویه | `#53655B` | `#B2C4B8` |
| زمینه      | `#F2F5F3` | `#101815` |
| متن CTA    | سفید      | `#09281B` |

- منبع رنگ، radius، shadow، typography و motion: `styles/tokens.css`.
- قراردادهای layout و وضعیت‌ها: `styles/base.css`.
- شیشه، responsive و اصلاحات RTL/LTR: `styles/design-system.css`.
- فونت فارسی: Vazirmatn محلی؛ انگلیسی: Inter محلی.
- Header شناور/چسبان و Footer نیمه‌شفاف؛ fallback خوانا بدون backdrop-filter.
- کارت‌ها semi-glass و کم‌سایه؛ blur مستقل به همه کارت‌ها تحمیل نشده است.
- لینک، فرم، مقایسه و فیلتر همان قرارداد قبلی را حفظ کرده‌اند.
- مسیر فارسی بدون prefix، انگلیسی با `/en`؛ حالت نور و زبان مستقل‌اند.
- ذرات تزئینی غیرتعاملی و کم‌تعدادتر در موبایل؛ توقف با reduced-motion، pause کاربر و مخفی شدن صفحه.

## توسعه کامپوننت جدید

از توکن‌ها استفاده کنید، رنگ ثابت جدید نسازید. کنترل عملیاتی focus-visible و نام دسترس‌پذیر داشته باشد. متن UI از `useI18n/getI18n`، مسیر داخلی از `i18n/navigation` و مقدار فیلتر از شناسه canonical استفاده کند. جهت layout با locale تغییر می‌کند؛ SKU/مدل/واحد باید مستقل LTR بمانند.

## بررسی

گزارش‌های هر دو زبان/تم، رابط مدیریت، WebKit/Chromium، عرض‌های ۳۲۰ تا ۱۹۲۰ و حفظ داده در `docs/redesign/qa/` و گزارش نهایی Redesign قرار دارند. عبور خودکار از آزمون‌ها جای بررسی سخت‌افزار واقعی و صفحه‌خوان را نمی‌گیرد.
